## Placeholder convention

Any token wrapped in leading/trailing underscores (e.g. an all-caps word
surrounded by underscores) in `config.json`, `zowe.config.json`, or any
`*.md` file is replaced by `generate_copies.py` using the matching key from
`copies_data.json`. Add more such tokens to those files as needed, then add
matching keys to every entry in `copies_data.json`.
